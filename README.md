# Multi Level Parking Lot Manager

## Project Description

Multi Level Parking Lot Manager is a Java-based console application designed to manage vehicle parking across multiple floors of a parking lot.

The system allows users to park vehicles, find available parking slots, search for parked vehicles, view parking status, remove vehicles, and calculate parking fees.
